# Student Task Manager User Guide

## Starting the application

From the repository directory, run:

```text
python main.py
```

## Available actions

1. **Add task:** Enter a title that is not empty.
2. **Display tasks:** View task identifiers, titles, and completion status.
3. **Complete task:** Enter the identifier displayed by the task list.
4. **Delete task:** Enter the identifier of the task to remove.
5. **Exit:** Close the application.
